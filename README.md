## Project Overview

Classical game theory typically studies equilibrium as a static solution concept. In contrast, Foster and Vohra investigate how equilibrium behavior can emerge dynamically when agents repeatedly interact and adapt their actions over time.

The central result of the paper establishes a connection between **calibrated forecasting** and **correlated equilibrium**, showing that players using calibrated predictions and best-response behavior will generate empirical play that converges to the set of correlated equilibria.

This project aims to provide an intuitive exposition of the paper, emphasizing the underlying ideas, notation, and theoretical significance rather than focusing solely on formal proofs.
